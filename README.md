A modern personal portfolio website built with React, Vite, and Express.

## About

This project is a full-stack portfolio application that showcases professional work, skills, and experience—built with a React frontend using Vite for fast development and an Express backend for API functionality.

## Features

- Modern React (v19) implementation
- Fast development experience with Vite
- Server-side API support with Express
- Concurrent development setup for both frontend and backend
- Clean project structure following best practices
- Responsive design for all devices

## Tech Stack

- **Frontend**: React 19, React Router v7
- **Backend**: Express.js
- **Build Tool**: Vite

## Getting Started

### Development

```bash
npm run dev
```
This runs both the Vite development server and Express backend concurrently.

### Production

```bash
npm run build
npm start
```
This builds the frontend and serves the application through Express.
